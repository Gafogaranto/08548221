# Voiceoftaade — MoneyPrinterTurbo Colab Launcher

## Open the notebook

[Open the notebook in Google Colab](https://colab.research.google.com/github/Gafogaranto/08548221/blob/main/Voiceoftaade_MoneyPrinterTurbo_Colab.ipynb)

## Run it in order

1. Open the notebook in Google Colab.
2. Run **1. Install MoneyPrinterTurbo**. Wait until it prints `INSTALLATION COMPLETE`.
3. Run **2. Launch the dashboard**.
4. The notebook uses Google Colab's built-in port display for Streamlit on port 8501. No ngrok token or third-party public tunnel is used.

## Notes

- Keep the same Colab runtime between installation and launch.
- Colab runtimes are temporary; a runtime reset removes the installed project.
- This notebook is a community launcher for the official [MoneyPrinterTurbo project](https://github.com/harry0703/MoneyPrinterTurbo).
